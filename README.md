# Local Champion

Одностраничный статический сайт компании Local Champion. Сборка не требуется: GitHub Pages публикует файлы прямо из корня репозитория.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой простой локальный HTTP-сервер из папки проекта. Основные файлы:

- `index.html` — структура страницы;
- `styles.css` — оформление, адаптивность, светлая и тёмная темы;
- `script.js` — все тексты RU/EN, переключение языка и отправка формы;
- `404.html` — страница ошибки;
- `favicon.svg` и `og-image.svg` — графика сайта.

## 1. Репозиторий и GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы этого проекта в ветку `main`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. Дождитесь, пока GitHub покажет опубликованный адрес.

## 2. Домен local-champion.kz

Файл `CNAME` уже содержит `local-champion.kz` — не удаляйте его.

В настройках репозитория откройте **Settings → Pages**, укажите `local-champion.kz` в поле **Custom domain** и сохраните. Когда GitHub выпустит сертификат, включите **Enforce HTTPS**.

## 3. DNS на hoster.kz

Добавьте у регистратора следующие записи:

| Тип | Имя / Host | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | `<github-username>.github.io` |

Замените `<github-username>` на имя владельца репозитория GitHub.

**Важно:** не изменяйте и не удаляйте существующие MX- и TXT-записи — они используются для электронной почты. Распространение DNS-изменений может занять до 24–48 часов.

## 4. Подключение Formspree

1. Создайте форму на [Formspree](https://formspree.io/).
2. Скопируйте её ID из адреса вида `https://formspree.io/f/abcdefgh`.
3. В `index.html` найдите:

   ```html
   action="https://formspree.io/f/YOUR_FORM_ID"
   ```

4. Замените `YOUR_FORM_ID` на полученный ID, например:

   ```html
   action="https://formspree.io/f/abcdefgh"
   ```

5. Опубликуйте изменения и отправьте тестовое сообщение.

Форма отправляется без перезагрузки страницы, показывает результат на выбранном языке, проверяет обязательные поля и содержит скрытое honeypot-поле против простого спама.

## Редактирование текста и добавление KZ

Все переводимые тексты находятся в объекте `translations` в начале `script.js`. Чтобы добавить казахский язык:

1. Скопируйте объект `ru` внутри `translations` и назовите копию `kz`.
2. Переведите значения, не меняя названия ключей.
3. В языковой переключатель в `index.html` и `404.html` добавьте кнопку:

   ```html
   <button type="button" data-lang="kz" aria-pressed="false">KZ</button>
   ```

JavaScript автоматически подключит новый язык, сохранит выбор посетителя и установит `<html lang="kz">`.
