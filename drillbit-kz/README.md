# Drillbit Kazakhstan

Интерактивный инвестиционный анализ производства штыревых буровых коронок в Казахстане.

## Что внутри

- оценка рынка и структуры импорта;
- продуктовая стратегия R32, T38, DHD350 и CIR;
- производственная цепочка и ключевые технологические риски;
- юнит-экономика, EBITDA, CAPEX и точка безубыточности;
- инвестиционные стоп-факторы и следующие шаги.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```
